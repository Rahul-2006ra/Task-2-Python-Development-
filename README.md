Automated Report Generator (Python)

A simple Python project that reads data from a CSV file, analyzes it, and generates a clean PDF report automatically.

🔧 Features
Reads data from data.csv
Calculates basic summary (total records, average, max, min)
Generates a formatted PDF report
Easy to run and modify

🚀 How to Run
Bash
pip install pandas reportlab
python main.py

📄 Output
The script creates:
Automated_Report.pdf (inside your project folder)

📂 Files Included
main.py
data.csv
Generated PDF
